# **DAY-1 :BOX MODEL -border padding & margin**

* **h1 {} is called selector**. We write it as:
    

`h1 {`

`color: red;`

`}`

* in case two tags are named h1, and we don’t need each tag to be red. So we use a class name. Now we target the class name and not the tag name. **Class name always start with a dot** as:
    

`.abc {`

`color : red;`

`}`

* We can use multiple class names within same tag.
    
* We can also use the same class name to other tags, in order to give the same propertiess.

DIFFERENCE BETWEEN FLEX-WRAP and MEDIA QUERY:

* FLEX-WRAP: used when you have maximum side-to-side and you want to wrap them automatically with screen size, you use flex wrap.
    
* MEDIA QUERY: If you want the elements to adjust with screen size based on any given customized properties of padding, color, margin, size, etc. then we use media query.

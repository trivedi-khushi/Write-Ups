**<mark>ANSWER:</mark>**

The difference between these two URLs lies in the query parameters that appear after the `?` in the first URL.

### Breakdown of the URLs:

1. **First URL:**
    
    ```plaintext
    https://docs.suprsend.com/docs/trigger-workflow?_gl=1*8j7y2q*_gcl_au*MTA2NTI3NzMyOC4xNzM3OTczMjgw*_ga*NzQzODYzNDE1LjE3Mzc5NzMyODA.*_ga_PPDYBESP2L*MTczODU4MjAwMi41LjEuMTczODU4NTkwMC42MC4wLjA.
    ```
    
    * This URL contains tracking parameters such as `_gl`, `_gcl_au`, and `_ga`.
        
    * These are commonly used by Google Analytics and other tracking tools to collect data about user activity, referrals, and marketing campaign performance.
        
2. **Second URL:**
    
    ```plaintext
    https://docs.suprsend.com/docs/trigger-workflow
    ```
    
    * This is a clean URL without any tracking parameters.
        
    * It loads the same page as the first URL but without any extra data for analytics.
        

### Key Differences:

* The first URL **tracks user behavior**, likely helping the website analyze where users are coming from and their interactions.
    
* The second URL is a **plain, direct link** to the page without tracking.
    

If you don’t need tracking, you can safely remove the query parameters and use the second URL.

**<mark>USER:</mark>**

what do we call these two urls by name or phenomena?

###### **<mark>ANSWER:</mark>**

The two URLs represent the concept of **"canonical vs. tracking (or parameterized) URLs."** Here are some relevant terms and phenomena associated with them:

### **1\. Canonical URL**

* The second URL ([`https://docs.suprsend.com/docs/trigger-workflow`](https://docs.suprsend.com/docs/trigger-workflow)) is the **canonical URL**, meaning it's the primary, clean version of the webpage's address.
    
* It doesn't include any tracking or session-based parameters and is often used for SEO and linking.
    

### **2\. URL with Tracking Parameters (Tracking URL)**

* The first URL ([`https://docs.suprsend.com/docs/trigger-workflow`](https://docs.suprsend.com/docs/trigger-workflow)`?...`) is a **tracking URL** or **parameterized URL** because it includes query parameters used for analytics and attribution.
    
* Parameters like `_gl`, `_gcl_au`, and `_ga` are commonly used by **Google Analytics, UTM tracking, and other marketing tools** to track user behavior, source of traffic, or campaign effectiveness.
    

### **3\. Query String Parameters**

* The portion after the `?` in the first URL is known as the **query string** or **URL parameters**.
    
* These parameters are key-value pairs (`key=value`) used to pass extra information between the browser and the web server.
    

### **4\. URL Normalization (or Canonicalization)**

* The process of stripping away unnecessary tracking parameters to get a clean, standard URL is called **URL normalization** or **canonicalization**.
    
* This is often done in SEO to avoid duplicate content issues caused by multiple versions of the same URL.
    

### **5\. Deep Linking & Attribution Tracking**

* URLs with parameters like `_gl` and `_gcl_au` are often used for **deep linking** and **conversion tracking**, where marketers track how users arrive at a website.
    
* Tools like Google Ads, Facebook Ads, and affiliate marketing platforms use such tracking URLs.
    

### **Conclusion**

In summary:

* The second URL is a **canonical URL** (clean and standard).
    
* The first URL is a **tracking URL** (parameterized for analytics).
    
* The extra parameters are **query string parameters** used for **tracking and attribution**.
    
* The concept of cleaning such URLs is called **URL normalization or canonicalization**.

He flags an important research-backed caution: **giving an agent more tools actually increases hallucination.** So fewer, better tools is a better strategy. They had to bring thousands of Razorpay APIs down to just a few tools:

1.  **GraphQL Tool** — 90% of all merchant dashboard queries already go through a GraphQL layer. It was a natural fit because: (a) skill creators don't need to hunt for specific APIs, and (b) the agent can query the graph as it sees fit.
    
2.  **REST API Tool** — for APIs not on GraphQL. Skill creators embed the exact REST API endpoint within the skill itself, so the agent can call it accurately.
    
3.  **N8N Workflows Tool** — for situations where they don't want the agent making autonomous decisions (especially around money movement, where even a 1% error rate could cause financial loss and merchant distrust). These deterministic workflows are exposed as a tool.
